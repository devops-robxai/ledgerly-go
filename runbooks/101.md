### Read a screenshot

`-p` and `--print` are the non-interactive flag. `--force` auto-allows commands. `--output-format json` works only with `--print`. stdout is one JSON object: `{"type":"result","subtype":"success","is_error":false,"duration_ms":...,"duration_api_ms":...,"result":"<reply string>","session_id":...,"request_id":...,"usage":{...}}`. `result` is a string. It may include prose and a json code fence. It is not bare JSON.

An image is read when its path is in the prompt. There is no image flag. Same pattern as a gameplay screenshot: point at the file. This one is `demo/screenshots/inv-1048-scale.png` (Scale invoice `inv_1048`, $249.00).

Do not claim any other flag.

```bash
cursor-agent -p --force "Read the image at demo/screenshots/inv-1048-scale.png. Reply with one sentence that includes the plan name and the invoice amount in USD. Do not edit files." --output-format json
```
